# FTP Server Configuration

## Project Overview
This project demonstrates FTP Server configuration using Cisco Packet Tracer.

## Objectives
- Configure an FTP Server.
- Understand File Transfer Protocol (FTP).
- Establish communication between clients and the server.
- Test file transfer functionality.

## Tools Used
- Cisco Packet Tracer
- FTP Server
- Switch
- Client PCs

## Testing
- Verify server connectivity.
- Test FTP client access.
- Test file transfer functionality.
