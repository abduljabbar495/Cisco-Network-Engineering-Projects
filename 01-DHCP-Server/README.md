# DHCP Server Configuration

## Project Overview
This project demonstrates DHCP Server configuration using Cisco Packet Tracer.

## Objectives
- Configure a DHCP Server.
- Assign IP addresses automatically to client PCs.
- Establish network connectivity.
- Test DHCP functionality.

## Tools Used
- Cisco Packet Tracer
- Router
- Switch
- DHCP Server
- Client PCs

## Testing
- Verify automatic IP assignment.
- Check IP configuration.
- Test connectivity using Ping.
