# Dynamic Routing Configuration

## Project Overview
This project demonstrates Dynamic Routing configuration using Cisco Packet Tracer.

## Objectives
- Configure dynamic routing between routers.
- Establish communication between different networks.
- Understand routing protocols.
- Verify network connectivity.

## Tools Used
- Cisco Packet Tracer
- Cisco Routers
- Switches
- PCs

## Testing
- Check routing tables.
- Test connectivity using Ping.
- Verify communication between networks.
