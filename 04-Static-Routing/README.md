# Static Routing Configuration

## Project Overview
This project demonstrates Static Routing configuration using Cisco Packet Tracer.

## Objectives
- Configure static routes on routers.
- Understand manual route configuration.
- Establish communication between different networks.
- Verify network connectivity.

## Tools Used
- Cisco Packet Tracer
- Cisco Routers
- Switches
- Client PCs

## Testing
- Verify routing table entries.
- Test connectivity using Ping.
- Check communication between different networks.
